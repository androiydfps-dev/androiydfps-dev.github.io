# Androiyd Voice Lab

Live site: https://androiydfps-dev.github.io/

On-device vocal coach. Pitch stays on the phone or laptop. Nothing is uploaded.

## What is in this repo

- Coach: live pitch, target lane (you vs the note), UP / DOWN / OK tips
- Songs: preloaded melody charts (Twinkle, Amazing Grace, five-note warmup) with a quiet guide tone
- Tune: on-device autotune (headphones recommended)
- Session: hold time and cents stats for the current visit

## Files

- `index.html` — UI
- `styles.css` — layout
- `app.js` — coach, songs, tune controls
- `worklets/pitch-detector.js` — pitch tracking
- `worklets/autotune.js` — correction engine
